🔤 Token

Token neden enerji harcar?

Yapay zeka kelimeleri bizim gibi okumaz; onları token denen parçalara böler. Her token, milyarlarca parametreden bir geçiş ister → GPU elektrik çeker → ısınır → soğutma suyu harcanır.

  • Girdi token'ı ucuz (toplu işlenir — "prefill").
  • Çıktı token'ı pahalı (tek tek, sırayla üretilir — "decode"). Cevap uzadıkça maliyet artar.
  • Kaba dönüşüm: ~1000 token ≈ 750 kelime (İngilizce).
"Sürdürülebilir yapay zeka" nasıl parçalanır?
Sürdürülebilir yapay zeka

Mit: "Önce İngilizceye çevriliyor" ❌ — Hayır. Tokenizer metni kendi dilinde doğrudan böler; ayrı bir çeviri adımı yoktur. Canlı denemek için Token Hesaplayıcı'ya geç.

🏢 Ölçek

Neden herkes model yapamıyor?

Frontier model eğitmek on/yüz milyonlarca dolar + dev enerji ister. Bu yüzden gerçek anlamda frontier model eğiten yalnızca ~8–10 kuruluş var.

Gördüğümüz yüzlerce "yapay zekâ uygulaması" çoğunlukla bu az sayıda temel modelin üstüne kurulu (API, ince ayar, sarmalayıcı). Yani "çok model" değil — az sayıda temel model + çok sayıda paketleme.
