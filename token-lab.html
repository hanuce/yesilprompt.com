🔤 Token nedir?

Token: yapay zekânın “hece”si

Yapay zekâ kelimeleri bizim gibi okumaz; metni token denen küçük parçalara böler (“Sürdür-üle-bilir” gibi). Token, hem öğrenmenin hem üretmenin birimidir: eğitimde model veriyi token token okur, kullanımda cevabı token token üretir.

  • Girdi token’ı ucuz — toplu işlenir (“prefill”).
  • Çıktı token’ı pahalı — tek tek üretilir (“decode”). Cevap uzadıkça maliyet artar.
  • Kaba dönüşüm: ~1000 token ≈ 750 kelime (İngilizce).

🌍 Multilingual

Bütün dilleri İngilizceye mi çeviriyor?

Hayır. Ayrı bir çeviri adımı yoktur.

  • Tokenizer metni kendi dilinde doğrudan alt-parçalara böler.
  • Aynı model onlarca dili aynı anda işleyebilir (multilingual), çünkü eğitim verisinde o diller de vardı.
  • Modern tokenizer’lar (o200k, Gemini) kısa/yaygın kelimelerde TR–EN farkını büyük ölçüde kapattı.
  • Fark, uzun, ekli, nadir kelimelerde belirginleşir. Sağdaki tabloda canlı gör.

Kaynak: Kamali (2024), Hugging Face — Tokenization & multilingual.

Türkçe vs İngilizce — token sayısı

“Su” ve “Water” benzer; ama “Sürdürülebilirlik” İngilizcesinden daha çok parçaya bölünebilir.
